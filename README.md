# 拾文 Shiwen

**把值得看的公众号文章，留下来。**

拾文是一个在自己电脑上运行的公众号文章收集小工具。把常看的公众号合集加进来，收集文章后，按日期和关键词筛选，再导出成 Excel。

适合平时整理学习资料、收集研究方向、保存行业文章，或者只是想把散落在微信里的内容整理成一张表。

## 先下载安装

👉 **[点击这里下载安装包](https://github.com/xiaoxin12138888-svg/shiwen/releases/latest)**，选择 `Shiwen-Windows-Setup.zip`。

1. 解压下载的压缩包。
2. 双击里面的 `拾文-Setup-1.0.0-Windows-x64.exe`，按提示安装。
3. 双击桌面上的 **拾文**，默认浏览器会自动打开工具页面。

支持 **Windows 10 / 11，Intel / AMD 64 位电脑**。不需要安装 Python、Node.js、Codex 或 Excel。安装包约 10 MB，里面也附有中文使用说明。

安装程序暂未购买代码签名证书，Windows 可能显示发布者未验证。

> 只是想使用工具的话，下载 Releases 里的安装包即可。GitHub 的 `Code → Download ZIP` 下载的是源码。

## 它能做什么

| 你想做的事 | 在拾文里怎么做 |
| --- | --- |
| 整理某个公众号的一个系列 | 添加这个公众号的公开合集链接，批量收集合集内的文章 |
| 保存几篇特定文章 | 粘贴微信文章分享链接，一行一条 |
| 从旧表格继续整理 | 导入已有的 `.xlsx` 文章表 |
| 找某段时间的文章 | 设置文章发布日期，起止当天都包含在内 |
| 只看感兴趣的主题 | 设置标题关键词，也可以搜索已收集的摘要和正文 |
| 去掉不想看的内容 | 设置排除关键词，比如“招聘、课程” |
| 下次继续用同一套筛选条件 | 保存为筛选方案 |
| 把结果带走 | 导出全部筛选结果，或只导出勾选的文章 |

文章和配置保存在本机。朋友安装后会从空文章库开始，每个人整理自己的内容。

## 第一次使用：跟着做就行

### 1. 找到公众号的合集链接

在微信里打开一篇文章，看看文章底部有没有“合集”。点击合集名称，进入合集页面后，复制分享链接。

合集链接通常包含 `mp.weixin.qq.com/mp/appmsgalbum` 和 `album_id`。

**没有合集也能用**：点击拾文里的“收集文章”，直接粘贴文章分享链接即可。

### 2. 添加公众号并收集

点击右上角 **管理公众号**，填写：

- **公众号名称**：尽量填写准确名称，程序会核对合集归属。
- **合集 / RSS 地址**：粘贴刚才复制的合集链接。

点击 **保存并收集**，等待收集结果。之后想更新文章，点击 **收集文章 → 公众号合集 / RSS → 开始收集**。

左侧勾选公众号后，只更新选中的来源；不勾选时更新所有已配置来源。

> 只填写公众号名称，程序还不知道去哪里找文章，需要同时提供合集链接或有效的 RSS/Atom 地址。

### 3. 用日期和关键词筛选

例如，你想找某个公众号在 9 月发布的“即插即用”或“注意力”相关文章：

1. 在左侧勾选这个公众号。
2. 将日期设为 `2026-09-01` 到 `2026-09-30`。
3. 在“包含关键词”里填 `即插即用，注意力`。
4. 选择 **包含任意一个**，点击 **筛选文章**。

如果希望两个词都出现，改选“同时包含全部”。多个关键词用逗号分隔。日期和关键词筛选的是**已经收集到本机的文章**。

### 4. 导出 Excel

点击 **导出筛选结果**；只想要几篇，就勾选后点 **导出勾选**。

导出表格包含 18 列：

```text
公众号、ID、链接、标题、封面、摘要、创建时间、发布时间、
阅读、点赞、分享、喜欢、留言、作者、是否原创、文章类型、所属合集、文章内容
```

没有获取到的数据会留空，不会编造阅读量或点赞数。正文超出 Excel 单元格容量时，导出会截短，完整内容仍保存在本机文章库里。

## 几个容易误会的地方

**能收集公众号全部历史文章吗？**

目前主要通过你提供的公开合集收集，只覆盖这个合集里的文章。作者没有加入合集的文章，不会自动出现。也可以另外粘贴文章链接或导入旧表格。

**为什么有标题和链接，却没有正文、阅读量？**

合集列表通常只提供标题、链接、发布时间等信息，不包含正文和阅读互动数据。需要正文时，可以尝试单独收集文章链接；实际能获取哪些字段取决于微信页面。

**为什么显示没有符合条件的文章？**

先看公众号旁边的文章篇数。如果是 0，先添加有效来源并收集；如果已经有文章，试试“不限日期”，清空关键词后再筛选。

**微信提示验证或采集失败怎么办？**

界面会显示失败原因。可以稍后重试，或在浏览器正常打开文章后保存为 HTML，再通过“导入表格 / 网页”导入。工具不绕过微信验证，也不能保证每篇文章都能成功读取。

**重复收集会出现两份吗？**

程序会按文章链接，以及可识别的公众号和文章 ID 合并重复记录。新获得的内容可以补充旧记录；无法确认是同一篇时，仍可能分别保留。

**必须联网吗？**

收集新文章需要联网。已经保存的文章可以离线筛选和导出。暂不提供定时自动收集，需要自己点击更新。

## 数据放在哪里？怎么备份？

安装版的数据保存在自己的 Windows 用户目录。按 `Win + R`，输入：

```text
%LOCALAPPDATA%\Shiwen\data
```

里面的 `library.sqlite3` 保存文章、公众号和筛选方案。

- **备份**：先退出拾文，再复制这个文件到安全的地方。
- **换电脑**：在新电脑安装并启动一次拾文，然后退出，用备份文件替换新电脑数据目录中的同名文件。
- **更新或卸载**：会保留数据，便于以后继续使用。
- **不同的人**：不同电脑、不同 Windows 用户各自保存数据；同一 Windows 用户下共用一份文章库。

拾文的页面只允许本机访问，没有云端账号，也不会把文章库上传到这个 GitHub 仓库。收集文章时，会访问你配置的微信或订阅源地址。

## 怎么退出？

点击页面底部 **退出拾文**，或在 Windows 开始菜单选择 **退出拾文**。下次双击桌面图标继续使用。

只关闭浏览器标签页，后台程序还会运行。正在收集时，先等待完成再退出。工具不会设置开机自启动。

## 想自己运行源码

普通使用者可以跳过这一节。

准备 Python 3.12，在项目目录运行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

然后在浏览器打开 <http://127.0.0.1:18765>。源码运行时，数据保存在项目的 `data` 目录；在终端按 `Ctrl + C` 停止服务。

项目用 Python 标准库提供本机服务和 SQLite 数据存储，用 openpyxl 读写 Excel。前端是普通 HTML、CSS 和 JavaScript，不需要 Node 构建。

```text
app.py                 收集、筛选、本机接口和 Excel 导入导出
desktop.py             Windows 独立程序启动入口
dist/                  页面文件
scripts/               Windows 打包脚本
packaging/             安装程序配置和使用说明
```

Windows 打包方法见 [打包说明](packaging/BUILD.md)。安装包仅包含程序和依赖，不包含开发者的数据库、本机配置或登录信息。
